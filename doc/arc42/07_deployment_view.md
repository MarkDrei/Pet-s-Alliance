# 7. Deployment View

Currently trivial: a standard Next.js app with no backend dependencies.

- `npm run dev` — local development server.
- `npm run build` / `npm run start` — production build and server. The app could equally be deployed to any Node-capable host or platform (e.g. Vercel).
- No environment variables, databases, or external services are required.

When the backend arrives (player DBs, meta-progression), this section must be extended with the service topology.
